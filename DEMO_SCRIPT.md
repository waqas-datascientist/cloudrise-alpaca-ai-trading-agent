# CloudRise — 90-second demo script

## Recording setup

Use the fresh Alpaca paper account, set `CLOUDRISE_MODE=paper`, open the dashboard at 1440×900, and keep the Alpaca account page ready in a second tab. Never show API keys. If the market is closed, use the clearly labeled demo replay and show prior real paper orders separately.

## Script and shot list

**0:00–0:10 — The hook**  
_Dashboard hero and equity curve._

“Most trading agents let the same black box invent a trade and authorize it. CloudRise separates intelligence from authority.”

**0:10–0:27 — The debate**  
_Scroll to Live Opportunity Board; point to SPY specialist votes._

“Every 15 minutes, four independent agents analyze Alpaca market data: regime, momentum, breakout, and mean reversion. Here, three agree on SPY. Confidence clears 84 percent, while QQQ is rejected because it cannot clear the threshold.”

**0:27–0:45 — Defined-risk options**  
_Show the selected SPY debit spread and maximum risk._

“The agent never buys a vague direction. It constructs a liquid 7-to-21-day vertical option spread from Alpaca's options chain. The long and short legs define the exact maximum loss before an order exists.”

**0:45–1:02 — Governance**  
_Show Risk Governor card._

“Research still has no trading authority. Eleven hard gates enforce the daily circuit breaker, confidence, consensus, liquidity, position limits, and a 2.5 percent portfolio risk ceiling. One failed gate means no trade, with no override.”

**1:02–1:17 — Alpaca execution**  
_Press Run agent cycle; then show the latest CLI sync and order record._

“After reconciling the account through Alpaca's official CLI, an approved setup becomes one atomic MLeg limit order in the required paper environment. A unique client ID prevents accidental duplicates.”

**1:17–1:28 — Proof**  
_Scroll to Immutable Decision Ledger and briefly switch to Alpaca activity._

“Every thesis, veto, risk decision, CLI call, and broker response is timestamped. Judges can inspect the reasoning and verify the paper activity.”

**1:28–1:30 — Close**

“CloudRise: conviction, with guardrails.”

## Before publishing

- Blur the paper account ID if the organizer has not said it may be public.
- Confirm the mode badge reads **ALPACA PAPER · AUTONOMOUS** for real activity or **DEMO REPLAY · PAPER ONLY** for replay.
- Keep the disclosure visible or add it to the video description.
- Use captions; many judges watch without sound.
